# Implementer rules (binding)
- Test first for every behaviour change: show RED (the failing test output) then GREEN in the report.
- Do exactly the task as briefed plus the controller rulings in the dispatch; no unrelated refactors. If the plan is impossible or contradicts a ruling, stop and report NEEDS_CONTEXT with the evidence.
- Report file: write the path you are given, with: commits, files changed, RED/GREEN evidence, full-suite counts, every deviation and why, concerns, and rollout items for the controller.
- Reply with the short status contract: status (DONE | DONE_WITH_CONCERNS | NEEDS_CONTEXT | BLOCKED), commits, test_summary, concerns.
